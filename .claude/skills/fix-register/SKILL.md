---
name: fix-register
description: Work through open items in the SILO-BZ planning register (docs/planning/OPEN_ITEMS.md)
---
1. Read `docs/planning/OPEN_ITEMS.md` and list the open items, one line each, with a short plan.
2. Take the first open item. Explore only what that item needs, make the fix, and verify it.
3. Update that item's status in the register with a short note on what changed.
4. Repeat for the next item. If an item is blocked, record why and move on.
5. End with a summary table showing each item, its status and the files changed.
