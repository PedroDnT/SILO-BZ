## Endpoint groups

The BACEN API is organized into four groups based on the underlying BACEN data source.

---

## SGS — Time Series

The SGS (Sistema Gerenciador de Séries Temporais) contains hundreds of official time series published by BACEN.

### Well-known series

```
GET /api/v1/bacen/sgs/well-known
```

Returns a curated list of commonly used series with their codes and descriptions.

**Example response**

```json
[
  { "code": 11, "name": "Selic rate (daily)" },
  { "code": 12, "name": "CDI rate (daily)" },
  { "code": 433, "name": "IPCA (monthly)" },
  { "code": 189, "name": "IGP-M (monthly)" }
]
```

---

### Single series

```
GET /api/v1/bacen/sgs/{series_code}
```

| Parameter | Type | Description |
|---|---|---|
| `series_code` | int | SGS series code |
| `start_date` | string | Start date `YYYY-MM-DD` (optional) |
| `end_date` | string | End date `YYYY-MM-DD` (optional) |

**Example — Selic rate for January 2025**

```bash
curl "http://localhost:8002/api/v1/bacen/sgs/11?start_date=2025-01-01&end_date=2025-01-31"
```

---

### Latest value

```
GET /api/v1/bacen/sgs/{series_code}/latest
```

Returns the most recent data point for a series.

```bash
curl "http://localhost:8002/api/v1/bacen/sgs/11/latest"
```

---

### Multiple series

```
GET /api/v1/bacen/sgs/multi
```

Fetch several series in one request using comma-separated codes.

| Parameter | Type | Description |
|---|---|---|
| `codes` | string | Comma-separated series codes, e.g. `11,12,433` |
| `start_date` | string | Start date (optional) |
| `end_date` | string | End date (optional) |

```bash
curl "http://localhost:8002/api/v1/bacen/sgs/multi?codes=11,12,433&start_date=2025-01-01"
```

## PTAX — Exchange Rates

Official exchange rates published daily by BACEN.

### USD/BRL — latest

```
GET /api/v1/bacen/ptax/usd/latest
```

### USD/BRL — date range

```
GET /api/v1/bacen/ptax/usd
```

| Parameter | Type | Description |
|---|---|---|
| `start_date` | string | Start date `YYYY-MM-DD` |
| `end_date` | string | End date `YYYY-MM-DD` |

```bash
curl "http://localhost:8002/api/v1/bacen/ptax/usd?start_date=2025-01-01&end_date=2025-01-31"
```

---

### Any currency — latest

```
GET /api/v1/bacen/ptax/{currency}/latest
```

| Parameter | Values (examples) |
|---|---|
| `currency` | `EUR`, `GBP`, `JPY`, `CHF`, `CAD`, `AUD` |

```bash
curl "http://localhost:8002/api/v1/bacen/ptax/EUR/latest"
```

---

### Any currency — date range

```
GET /api/v1/bacen/ptax/{currency}
```

Same query parameters as the USD endpoint above.

## Expectativas — Focus Market Expectations

Focus is the weekly BACEN survey of market expectations for key macroeconomic indicators.

### Available expectation endpoints

```
GET /api/v1/bacen/expectativas/endpoints
```

Returns the full list of available expectation types.

---

### Market expectations

```
GET /api/v1/bacen/expectativas/{endpoint}
```

| Parameter | Values (examples) |
|---|---|
| `endpoint` | `ExpectativasMercadoAnuais`, `ExpectativasMercadoMensais`, `ExpectativasMercadoInflacao12Meses` |

| Query parameter | Type | Description |
|---|---|---|
| `indicator` | string | Indicator name, e.g. `IPCA`, `PIB Total`, `Selic` |
| `start_date` | string | Start date `YYYY-MM-DD` (optional) |
| `end_date` | string | End date `YYYY-MM-DD` (optional) |
| `top` | int | Limit number of results (optional) |

**Example — annual IPCA expectations**

```bash
curl "http://localhost:8002/api/v1/bacen/expectativas/ExpectativasMercadoAnuais?indicator=IPCA&top=10"
```

## TaxaJuros — Interest Rate Table

BACEN OData interest-rate table with credit modalities and rates.

```
GET /api/v1/bacen/taxas_juros
```

| Query parameter | Type | Description |
|---|---|---|
| `top` | int | Limit results (optional) |
| `modalidade` | string | Credit modality filter (optional) |

```bash
curl "http://localhost:8002/api/v1/bacen/taxas_juros?top=20"
```
