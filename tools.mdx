## Backfill CLI

The backfill tool bulk-downloads historical CVM data and resumes interrupted downloads automatically. Run it from the repository root.

### Backfill a single entity and document type

```bash
python -m src.tools.backfill --entity FIDC --doc-type INF_MENSAL
```

### Backfill all configured entities

```bash
python -m src.tools.backfill --all
```

### Options

| Flag | Description |
|---|---|
| `--entity` | Entity name (`FIDC`, `FIP`, `FIAGRO`, `SECURIT`) |
| `--doc-type` | Document type (e.g. `INF_MENSAL`, `CADASTRAL`) |
| `--all` | Run all configured entity/doc-type combinations |
| `--resume` | Resume from last checkpoint (enabled by default) |

The tool writes progress to a JSON file so you can stop and restart without re-downloading files that already completed.

## Endpoint checker

Quickly test all live CVM endpoints and report HTTP status, response size, and timing.

### Check all endpoints

```bash
python scripts/check_all_endpoints.py
```

### Check a specific entity

```bash
python scripts/check_all_endpoints.py --entity fidc --rows 5
```

### Options

| Flag | Description |
|---|---|
| `--entity` | Limit checks to one entity (`fidc`, `fip`, `fiagro`, `securit`) |
| `--rows` | Number of rows to request per endpoint (default: 1) |

## Running tests

The test suite runs from the repository root with `PYTHONPATH` set so that `src.*` imports resolve correctly.

```bash
# All tests
PYTHONPATH=. pytest tests/ -v

# Specific file
PYTHONPATH=. pytest tests/test_csv_parsing.py -v

# Specific test
PYTHONPATH=. pytest tests/test_cvm_url_patterns.py::test_fidc_url -v

# By marker
PYTHONPATH=. pytest tests/ -m unit -v
PYTHONPATH=. pytest tests/ -m "not slow" -v
```

**Available markers:** `unit`, `integration`, `slow`, `cvm`, `validation`, `parsing`
