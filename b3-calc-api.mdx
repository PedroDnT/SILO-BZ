## Overview

The B3 CALC API wraps `calculadorarendafixa.com.br` to provide unit price (PU), yield, duration, and other pricing metrics for Brazilian fixed income securities.

**Supported security types:**

| Type | Description | Symbol examples |
|---|---|---|
| `debentures` | Corporate debentures | `XPCA11`, `VALE13` |
| `cra` | Agro receivables certificates | `CRA021001PV` |
| `cri` | Real estate receivables certificates | `CRI021001PV` |

**Fallback behavior:** When the upstream is unavailable, the API returns built-in sample data so you can develop and test without a live connection.

### Get security price

```
GET /api/v1/prices/{symbol}
```

Calculate the unit price and yield metrics for a specific security.

**Path parameters**

| Parameter | Type | Description |
|---|---|---|
| `symbol` | string | Security code (case-insensitive) |

**Query parameters**

| Parameter | Type | Required | Description |
|---|---|---|---|
| `security_type` | string | No | `debentures`, `cra`, or `cri`. Auto-detected if omitted. |
| `settlement_date` | string | No | Settlement date `YYYY-MM-DD`. Defaults to today. |

**Example**

```bash
curl "http://localhost:8001/api/v1/prices/XPCA11"
```

**Response**

```json
{
  "code": "XPCA11",
  "security_type": "debentures",
  "security_info": {
    "code": "XPCA11",
    "name": "XP Credito Agro",
    "issuer": "XP Investimentos",
    "security_type": "debentures",
    "index": "CDI",
    "rate": 1.12,
    "maturity_date": "2028-06-15"
  },
  "price": {
    "pu": 1043.21,
    "pu_par": 104.32,
    "yield_rate": 0.1245,
    "duration": 912,
    "modified_duration": 886,
    "dv01": 0.0923,
    "accrued_interest": 12.34,

    "reference_rate": 0.1065

}
```

### List securities by type

```
GET /api/v1/securities/{security_type}
```

List available securities of a given type with optional search and pagination.

**Path parameters**

| Parameter | Values |
|---|---|
| `security_type` | `debentures`, `cra`, `cri` |

**Query parameters**

| Parameter | Type | Required | Description |
|---|---|---|---|
| `page` | int | No | Page number (default: 1) |
| `page_size` | int | No | Records per page (default: 100, max: 10000) |
| `search` | string | No | Filter securities by name or code |

**Example — search for debentures by name**

```bash
curl "http://localhost:8001/api/v1/securities/debentures?search=petrobras&page_size=10"
```

**Response**

```json
{
  "security_type": "debentures",
  "page": 1,
  "page_size": 10,
  "total": 3,
  "securities": [
    {
      "code": "PETR21",
      "name": "Petrobras 2021",
      "issuer": "Petróleo Brasileiro S.A.",
      "security_type": "debentures",
      "index": "IPCA",
      "rate": 5.25,
      "maturity_date": "2031-03-15"
    }
  ],
  "timestamp": "2026-02-25T12:00:00+00:00"
}
```

## Caching

Responses are cached in memory with a **30-minute TTL** and a maximum of 64 entries. Each unique `(symbol, security_type, settlement_date)` combination is cached independently. The `cached` field in the price response indicates whether the result came from cache.

---

## Configuration

Set `B3_CALC_BASE_URL` in your `.env` file to point to a different upstream:

```bash
B3_CALC_BASE_URL=https://calculadorarendafixa.com.br/webservice
```

If the upstream is unreachable, the API automatically falls back to built-in sample data for debentures, CRA, and CRI. This behavior is intentional and preserved to support offline development.
