# CVM Credit Market API

Base URL: `http://localhost:8000`

- Interactive docs: [Swagger UI](http://localhost:8000/docs)
- OpenAPI schema: [openapi.json](http://localhost:8000/openapi.json)

## Endpoints
- `GET /api/v1/fidc/{doc_type}`
- `GET /api/v1/fip/{doc_type}`
- `GET /api/v1/fiagro/{doc_type}`
- `GET /api/v1/securit/{doc_type}`

See the interactive API docs or OpenAPI schema above for details on supported document types and query parameters.
