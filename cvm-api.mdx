### FIDC data

```
GET /api/v1/fidc/{doc_type}
```

Retrieve FIDC (Fundo de Investimento em Direitos Creditórios) data.

**Path parameters**

| Parameter | Values |
|---|---|
| `doc_type` | `mensal`, `cadastral`, `trimestral`, `anual` |

**Query parameters**

| Parameter | Type | Required | Description |
|---|---|---|---|
| `year` | int | Conditional | Year (required for `mensal`, `trimestral`, `anual`) |
| `month` | int | Conditional | Month 1–12 (required for `mensal`) |
| `page` | int | No | Page number (default: 1) |
| `page_size` | int | No | Records per page (default: 100, max: 10000) |

**Example — fetch FIDC monthly data**

```bash
curl "http://localhost:8000/api/v1/fidc/mensal?year=2025&month=1&page=1&page_size=5"
```

**Path parameters**

| Parameter | Values |
|---|---|
| `doc_type` | `inf_quadrimestral`, `inf_trimestral`, `cadastral`, `dfin` |

```bash

```

**Path parameters**

## Data quality

The service validates every parsed CSV against entity-specific rules:

- **CNPJ fields** — checksum validation via `src/validation_utils.py`
- **Date fields** — format and range checks
- **Numeric fields** — type coercion verification

Validation errors and warnings are included in the `metadata.data_quality` object.

## Caching

Downloaded files are cached on disk for **24 hours** under `cache/`. The cache is keyed by URL MD5. You can clear the cache by deleting the `cache/` directory.

## DNS resilience

If `dados.cvm.gov.br` is unreachable, the service rotates through configurable DNS resolvers (default: `1.1.1.1`, `8.8.8.8`, `9.9.9.9`). Set `CVM_DNS_NAMESERVERS` in your `.env` file to override.
