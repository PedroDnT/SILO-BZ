# Project Brief

## Purpose

Provide programmatic access to Brazilian financial market data from public regulatory sources (CVM, BACEN, B3) for quantitative analysis and credit market research.

## Target Users

- Quantitative analysts and researchers
- Fintech companies building credit products
- Investment managers analyzing Brazilian fixed income
- Academic researchers studying emerging market credit

## Services

| Service     | Port | Data Source                 |
| ----------- | ---- | --------------------------- |
| CVM API     | 8000 | dados.cvm.gov.br            |
| BACEN API   | 8002 | python-bcb wrapper          |
| B3 CALC API | 8001 | calculadorarendafixa.com.br |
