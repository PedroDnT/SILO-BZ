## Overview

Split one share's daily return variance into the Ibovespa, a B3 sector index made orthogonal to it, and the residual specific to the stock. One row with the three shares (they add to 1), betas, hedge ratios per R$ 1 long, annualized volatilities and the same split without shock sessions. Realized and historical only, not investment advice.
