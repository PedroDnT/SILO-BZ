## Example

```bash
curl --request GET 'https://zcjbtpxuhdekpwcxmepn.supabase.co/functions/v1/silo-api/v2/macro/series?series=CDI&limit=1' \
  --header "Authorization: Bearer $SILO_TOKEN"
```

<Accordion title="Series codes and units">

- `SELIC_META`: Selic target — % per year.
- `SELIC_DIARIA`: Selic daily rate — % per business day.
- `CDI`: CDI daily rate — % per business day.
- `IGPM`: IGP-M inflation — % per month.
- `INPC`: INPC inflation — % per month.
- `POUPANCA`: Savings return (old rule) — % per anniversary period.
- `USDBRL`: US dollar exchange rate — BRL per USD.
- `EURBRL`: Euro exchange rate — BRL per EUR.
- `PIB`: Monthly GDP — BRL millions.
- `DBGG_PIB`: Gross government debt — % of GDP.
- `NFSP_PRIMARIO_12M`: Primary borrowing requirement (12 months) — % of GDP.
- `NFSP_NOMINAL_12M`: Nominal borrowing requirement (12 months) — % of GDP.
- `DLSP_PIB`: Net public-sector debt — % of GDP.

</Accordion>
