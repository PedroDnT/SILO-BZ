## Overview

Debentures, commercial notes, CRI, CRA and other debt one listed company describes in its CVM FRE, yearly from 2010. One row is one issue as filed, often several series, with no ticker or ISIN. Rate and indexer appear only in terms_text, unparsed. Companies that file no FRE are not covered.


## Coverage

Coverage varies by dataset and date. [Check current dataset coverage](/api-docs/v2/operations/coverage/freshness) before drawing conclusions from missing data.
