## 2. You cannot generate an API key

The Data API does **not** issue keys. There is no signup, no OAuth, no
`createApiKey`. Every caller uses the same project **anon / public** JWT from
Supabase. That key is public by design (safe in a browser). `service_role` is
not.

An agent that tries to mint, hash, or invent a JWT will get `401`. A human
(project owner) copies **anon / public** once from the Supabase dashboard
(Settings → API) and either:

- exports `SILO_ANON_KEY`, or
- publishes it in [quickstart](/api-docs/quickstart) so agents can call with no human in the loop.

Until that value is on the page, **do not guess it**. Answer method from the
docs; refuse a live market conclusion if you cannot call `coverage`.

```bash
export SILO_URL="https://zcjbtpxuhdekpwcxmepn.supabase.co/rest/v1"
export SILO_ANON_KEY="..."   # anon/public only — never service_role
```

Every request needs both headers: `apikey` and `Authorization: Bearer`.

## 3. First live call is always `coverage`

```bash
curl -s -X POST "$SILO_URL/rpc/coverage" \
  -H "apikey: $SILO_ANON_KEY" \
  -H "Authorization: Bearer $SILO_ANON_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```

Three rows: quotes, funds, and the other published datasets with a latest date.
A `401` is missing/wrong anon headers. Empty/error body is a failed fetch —
**raise**, do not invent a last date.

## 4. Broad finance questions

Example: *does Brazilian equity stress show up in FIDC credit?*

1. `lookup` / `search_funds` for FIDC CNPJs. Do not invent a ticker→fund join.
2. `panel` with `p_ids: ["PETR4", "<cnpj>", ...]`, `p_metrics: ["close_return","delinquency","nav"]`, `p_freq: "month"`.
3. Pivot locally. Correlate pairwise-complete. **No ffill.**
4. `delinquency` is BRL outstanding, not a rate — divide by `nav`.
5. Quotes are unadjusted. A missing month is not a two-month return.

There is no server-side `corr`. If `panel` returns 100,001 rows, the cap fired —
do not analyze it. Details: [panel](/api-docs/panel), [conventions](/api-docs/conventions).

## 5. Integrity (same rules as humans)

<Warning>
  Never fabricate a price, NAV, fill, ranking, or ticker↔CNPJ match. Null stays
  null. Unknown id → no row. Known id, empty window → empty series, not a
  guessed last close.
</Warning>

Ingest (`run_daily`, landing tables) is out of scope for this API.
