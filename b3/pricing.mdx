## Overview

The B3 pricing endpoint calculates theoretical prices, yields, and other metrics for fixed income securities based on market conditions and security characteristics.

## Get Security Price

Calculate price data for a specific security:

```bash
curl "https://api.financialdata.com.br/api/v1/prices/PETR20?security_type=debentures&settlement_date=2024-01-15"
```

### Parameters

- `symbol` (path, required): Security symbol/code
- `security_type` (query, optional): Security type (debentures, cra, cri). Auto-detected if not provided
- `settlement_date` (query, optional): Settlement date in YYYY-MM-DD format (defaults to today)

### Response

```json
{
  "symbol": "PETR20",
  "security_type": "debentures",
  "settlement_date": "2024-01-15",
  "pricing": {
    "price": 1023.45,
    "yield": 12.35,
    "duration": 3.2,
    "convexity": 15.8,
    "accrued_interest": 5.67
  },
  "security_details": {
    "issuer": "Petrobras",
    "maturity_date": "2027-06-15",
    "coupon_rate": 11.5,
    "index": "CDI",
    "index_percentage": 105.0
  },
  "market_data": {
    "cdi_rate": 11.65,
    "reference_date": "2024-01-15"
  },
  "timestamp": "2024-01-15T10:30:00Z"
}
```

## Pricing Metrics

### Price

The theoretical market price of the security, typically expressed as a percentage of face value or in currency units.

### Yield

The expected return on the security, expressed as an annual percentage rate.

### Duration

A measure of the security's price sensitivity to interest rate changes. Higher duration means greater sensitivity.

### Convexity

A measure of how duration changes as interest rates change. Important for risk management.

### Accrued Interest

Interest that has accumulated since the last coupon payment but hasn't been paid yet.

## Index Types

### CDI-Linked

Securities linked to the CDI (Certificado de Depósito Interbancário) rate:

```bash
curl "https://api.financialdata.com.br/api/v1/prices/ITAU25?security_type=debentures"
```

Typical format: CDI + spread (e.g., 105% of CDI)

### IPCA-Linked

Securities linked to the IPCA inflation index:

```bash
curl "https://api.financialdata.com.br/api/v1/prices/ELET26?security_type=debentures"
```

Typical format: IPCA + fixed rate (e.g., IPCA + 5.5%)

### Fixed Rate

Securities with fixed coupon rates:

```bash
curl "https://api.financialdata.com.br/api/v1/prices/VALE24?security_type=debentures"
```

## Settlement Date

The settlement date affects pricing calculations:

```bash
# Price for today
curl "https://api.financialdata.com.br/api/v1/prices/PETR20"

# Price for future settlement
curl "https://api.financialdata.com.br/api/v1/prices/PETR20?settlement_date=2024-02-01"
```

## Code Examples

<CodeGroup>

```python Python
import requests
from datetime import date, timedelta

# Get current price
response = requests.get(
    "https://api.financialdata.com.br/api/v1/prices/PETR20",
    params={"security_type": "debentures"}
)
pricing = response.json()

print(f"Price: {pricing['pricing']['price']}")
print(f"Yield: {pricing['pricing']['yield']}%")
print(f"Duration: {pricing['pricing']['duration']}")

# Get price for future settlement
future_date = (date.today() + timedelta(days=30)).isoformat()
response = requests.get(
    "https://api.financialdata.com.br/api/v1/prices/PETR20",
    params={
        "security_type": "debentures",
        "settlement_date": future_date
    }
)
future_pricing = response.json()
```

```javascript JavaScript
// Get current price
const response = await fetch(
  'https://api.financialdata.com.br/api/v1/prices/PETR20?security_type=debentures'
);
const pricing = await response.json();

console.log(`Price: ${pricing.pricing.price}`);
console.log(`Yield: ${pricing.pricing.yield}%`);
console.log(`Duration: ${pricing.pricing.duration}`);

// Get price for future settlement
const futureDate = new Date();
futureDate.setDate(futureDate.getDate() + 30);
const futureResponse = await fetch(
  `https://api.financialdata.com.br/api/v1/prices/PETR20?security_type=debentures&settlement_date=${futureDate.toISOString().split('T')[0]}`
);
const futurePricing = await futureResponse.json();
```

```java Java
import java.net.http.*;

    HttpResponse.BodyHandlers.ofString());
```

## Error Handling

### Security Not Found

```json
{
  "error": "not_found",
  "message": "Security INVALID not found",
  "status_code": 404,
  "timestamp": "2024-01-15T10:30:00Z"
}
```

### Invalid Date

```json
{
  "error": "validation_error",
  "message": "Invalid settlement date format",
  "status_code": 422,
  "timestamp": "2024-01-15T10:30:00Z"
}
```

## Rate Limits

- 100 requests per minute per IP
- Pricing calculations may take 1-3 seconds
- Consider caching results for frequently accessed securities
