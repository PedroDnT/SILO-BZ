## Introduction

The CVM (Comissão de Valores Mobiliários) API provides access to comprehensive credit market data from Brazil's Securities and Exchange Commission. This includes data on investment funds, securitization operations, and other credit instruments.

## Document Types

Each entity supports different document types:

  <Accordion title="mensal - Monthly Information">

## Quick Start

### Get FIDC Registration Data

```bash
GET /api/v1/cvm/fidc/cadastral?page=1&page_size=100
```

<CodeGroup>

```python Python
import requests

response = requests.get(
    "https://api.financialdata.com.br/api/v1/cvm/fidc/cadastral",
    headers={"X-API-Key": "your_api_key"},
    params={"page": 1, "page_size": 100}
)

funds = response.json()['data']
for fund in funds:
    print(f"{fund['DENOM_SOCIAL']} - {fund['SIT']}")
```

```javascript JavaScript
const response = await fetch(
    'https://api.financialdata.com.br/api/v1/cvm/fidc/cadastral?page=1&page_size=100',
    { headers: { 'X-API-Key': 'your_api_key' } }
);

const { data: funds } = await response.json();
funds.forEach(fund => {
    console.log(`${fund.DENOM_SOCIAL} - ${fund.SIT}`);
});
```

</CodeGroup>

### Get Monthly Data with Date Filter

```bash
GET /api/v1/cvm/fidc/mensal?year=2024&month=1&page=1&page_size=50
```

<CodeGroup>

```python Python
response = requests.get(
    "https://api.financialdata.com.br/api/v1/cvm/fidc/mensal",
    headers={"X-API-Key": "your_api_key"},
    params={
        "year": 2024,
        "month": 1,
        "page": 1,
        "page_size": 50
    }
)

monthly_data = response.json()['data']
```

```javascript JavaScript
const response = await fetch(
    'https://api.financialdata.com.br/api/v1/cvm/fidc/mensal?year=2024&month=1&page=1&page_size=50',
    { headers: { 'X-API-Key': 'your_api_key' } }
);

const { data: monthlyData } = await response.json();
```

</CodeGroup>

## Data Format

CVM data is returned in CSV format from the source and parsed into JSON. Field names are preserved from the original CVM files:

```json
{
  "CNPJ_FUNDO": "12.345.678/0001-90",
  "DENOM_SOCIAL": "FUNDO EXEMPLO FIDC",
  "DT_REG": "2020-01-15",
  "DT_CANCEL": null,
  "SIT": "ATIVO",
  "TP_FUNDO": "FIDC"
}
```

<Note>
  Field names use Portuguese abbreviations as they appear in official CVM documents. Refer to CVM documentation for field definitions.
</Note>
