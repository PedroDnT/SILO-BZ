## Operation Types

The CVM API provides access to various types of credit market operations:

## Document Types by Entity

### FIDC (Receivables Investment Funds)

<Tabs>
  <Tab title="cadastral">
    **Registration Data**
    
    Basic fund information including:
    - CNPJ and fund name
    - Registration date
    - Cancellation date (if applicable)
    - Current status
    - Fund type
    
    ```bash
    GET /api/v1/cvm/fidc/cadastral
    ```
  </Tab>
  
  <Tab title="mensal">
    **Monthly Information**
    
    Detailed monthly reports (requires year and month):
    - Portfolio composition
    - Asset values
    - Performance metrics
    - Risk indicators
    
    ```bash
    GET /api/v1/cvm/fidc/mensal?year=2024&month=1
    ```
  </Tab>
  
  <Tab title="trimestral">
    **Quarterly Information**
    
    Quarterly financial reports:
    - Quarterly performance
    - Asset allocation
    - Fee structure
    - Investor information
    
    ```bash
    GET /api/v1/cvm/fidc/trimestral?year=2024
    ```
  </Tab>
  
  <Tab title="anual">
    **Annual Information**
    
    Comprehensive annual reports:
    - Annual performance summary
    - Complete financial statements
    - Auditor reports
    - Governance information
    
    ```bash
    GET /api/v1/cvm/fidc/anual?year=2023
    ```
  </Tab>
</Tabs>

## Common Use Cases

### Monitor Fund Status

```python
import requests

def get_active_funds(entity="fidc"):
    """Get all currently active funds"""
    response = requests.get(
        f"https://api.financialdata.com.br/api/v1/cvm/{entity}/cadastral",
        headers={"X-API-Key": "your_api_key"},
        params={"status": "ATIVO", "page_size": 1000}
    )
    return response.json()['data']

active_fidcs = get_active_funds("fidc")
print(f"Active FIDC funds: {len(active_fidcs)}")
```

### Track Monthly Performance

```python
def get_monthly_data(entity, year, month):
    """Get monthly data for a specific period"""
    response = requests.get(
        f"https://api.financialdata.com.br/api/v1/cvm/{entity}/mensal",
        headers={"X-API-Key": "your_api_key"},
        params={"year": year, "month": month, "page_size": 500}
    )
    return response.json()['data']

# Get January 2024 data
jan_2024 = get_monthly_data("fidc", 2024, 1)
```

### Historical Analysis

```python
from datetime import datetime, timedelta

def get_historical_data(entity, months=12):
    """Get historical data for the last N months"""
    all_data = []
    current_date = datetime.now()
    
    for i in range(months):
        date = current_date - timedelta(days=30 * i)
        data = get_monthly_data(entity, date.year, date.month)
        all_data.extend(data)
    
    return all_data

# Get last 12 months of data
historical = get_historical_data("fidc", 12)
```

## Data Quality

<Note>
  CVM data is sourced directly from official regulatory filings. Data quality depends on the accuracy of issuer submissions.
</Note>

### Validation Checks

Always validate critical fields:

```python
def validate_fund_data(record):
    """Validate fund record"""
    required_fields = ['CNPJ_FUNDO', 'DENOM_SOCIAL', 'DT_REG', 'SIT']
    
    for field in required_fields:
        if field not in record or record[field] is None:
            raise ValueError(f"Missing required field: {field}")
    
    # Validate CNPJ format
    cnpj = record['CNPJ_FUNDO']
    if not re.match(r'^\d{2}\.\d{3}\.\d{3}/\d{4}-\d{2}$', cnpj):
        raise ValueError(f"Invalid CNPJ format: {cnpj}")
    
    # Validate status
    valid_statuses = ['ATIVO', 'CANCELADO', 'SUSPENSO']
    if record['SIT'] not in valid_statuses:
        raise ValueError(f"Invalid status: {record['SIT']}")
    
    return True
```

## Rate Limits for CVM Endpoints

CVM endpoints share the same rate limits as other API endpoints:

- Free tier: 100 requests/minute
- Professional: 1,000 requests/minute
- Enterprise: Custom limits

<Tip>
  Use pagination and filtering to minimize the number of requests needed
</Tip>
