## Entity Types

The CVM API provides data for four main entity types, each representing different investment vehicles in the Brazilian credit market.

## FIDC - Fundos de Investimento em Direitos Creditórios

**Receivables Investment Funds**

<Card title="What are FIDCs?" icon="building-columns">
  Investment funds that primarily invest in credit rights (receivables) such as credit card receivables, auto loans, mortgages, and other debt instruments.
</Card>

### Key Characteristics

- Minimum 50% of assets must be credit rights
- Can be open or closed-end funds
- Regulated by CVM Instruction 356/2001
- Popular for credit securitization

### Available Data

<Tabs>
  <Tab title="Registration">
    - CNPJ and fund name
    - Registration date
    - Administrator information
    - Fund classification
    - Current status
  </Tab>
  
  <Tab title="Monthly">
    - Net asset value
    - Number of quotas
    - Quota value
    - Portfolio composition
    - Credit quality metrics
  </Tab>
  
  <Tab title="Quarterly">
    - Detailed portfolio breakdown
    - Risk metrics
    - Fee structure
    - Performance indicators
  </Tab>
  
  <Tab title="Annual">
    - Annual performance
    - Audited financial statements
    - Governance reports
    - Compliance information
  </Tab>
</Tabs>

### Example Usage

```python
# Get all active FIDC funds
response = requests.get(
    "https://api.financialdata.com.br/api/v1/cvm/fidc/cadastral",
    headers={"X-API-Key": "your_api_key"},
    params={"status": "ATIVO"}
)

fidcs = response.json()['data']
print(f"Total active FIDCs: {len(fidcs)}")
```

## FIP - Fundos de Investimento em Participações

**Private Equity Investment Funds**

<Card title="What are FIPs?" icon="briefcase">
  Investment funds that invest in equity stakes of companies, typically targeting private companies or taking significant positions in public companies.
</Card>

### Key Characteristics

- Minimum 90% in equity investments
- Long-term investment horizon
- Active participation in portfolio companies
- Regulated by CVM Instruction 578/2016

### Available Data

<Tabs>
  <Tab title="Registration">
    - Fund identification
    - Investment strategy
    - Target sectors
    - Management team
  </Tab>
  
  <Tab title="Quarterly">
    - Portfolio companies
    - Investment values
    - Ownership percentages
    - Performance metrics
  </Tab>
  
  <Tab title="Four-Month">
    - Detailed company information
    - Valuation methods
    - Exit strategies
    - Risk assessments
  </Tab>
  
  <Tab title="Financial Statements">
    - Balance sheet
    - Income statement
    - Cash flow statement
    - Notes to financial statements
  </Tab>
</Tabs>

### Example Usage

```python
# Get FIP quarterly information
response = requests.get(
    "https://api.financialdata.com.br/api/v1/cvm/fip/inf_trimestral",
    headers={"X-API-Key": "your_api_key"},
    params={"year": 2024}
)

fip_data = response.json()['data']
```

## FIAGRO - Fundos de Investimento nas Cadeias Produtivas Agroindustriais

**Agribusiness Investment Funds**

<Card title="What are FIAGROs?" icon="wheat">
  Investment funds focused on the agricultural and agribusiness sectors, investing in rural properties, agribusiness companies, and agricultural credit rights.
</Card>

### Key Characteristics

- Minimum 67% in agribusiness assets
- Tax benefits for investors
- Focus on agricultural value chain
- Regulated by Law 14.130/2021

### Available Data

Similar structure to FIDC:
- Registration data (cadastral)
- Monthly information (mensal)
- Quarterly information (trimestral)
- Annual information (anual)

### Example Usage

```python
# Get FIAGRO monthly data
response = requests.get(
    "https://api.financialdata.com.br/api/v1/cvm/fiagro/mensal",
    headers={"X-API-Key": "your_api_key"},
    params={"year": 2024, "month": 1}
)

fiagro_data = response.json()['data']
```

## SECURIT - Operações de Securitização

**Securitization Operations**

<Card title="What is SECURIT?" icon="file-contract">
  Various types of securitization operations including CRA, CRI, LCA, LCI, and other structured credit instruments.
</Card>

### Securitization Types

<AccordionGroup>
  <Accordion title="CRA - Certificados de Recebíveis do Agronegócio" icon="tractor">
    **Agribusiness Receivables Certificates**
    
    Securities backed by agribusiness receivables. Tax-exempt for individual investors.
    
    ```bash
    GET /api/v1/cvm/securit/cra_mensal?year=2024&month=1
    ```
  </Accordion>
  
  <Accordion title="CRI - Certificados de Recebíveis Imobiliários" icon="building">
    **Real Estate Receivables Certificates**
    
    Securities backed by real estate receivables. Tax-exempt for individual investors.
    
    ```bash
    GET /api/v1/cvm/securit/cri_mensal?year=2024&month=1
    ```
  </Accordion>
  
  <Accordion title="LCA - Letras de Crédito do Agronegócio" icon="seedling">
    **Agribusiness Credit Bills**
    
    Bank-issued securities backed by agribusiness loans. Tax-exempt.
    
    ```bash
    GET /api/v1/cvm/securit/lca_mensal?year=2024&month=1
    ```
  </Accordion>
  
  <Accordion title="LCI - Letras de Crédito Imobiliário" icon="house">
    **Real Estate Credit Bills**
    
    Bank-issued securities backed by real estate loans. Tax-exempt.
    
    ```bash
    GET /api/v1/cvm/securit/lci_mensal?year=2024&month=1
    ```
  </Accordion>
  
  <Accordion title="OTS - Other Securitization Operations" icon="file-lines">
    **Other Securitization Types**
    
    Other types of securitization operations not classified above.
    
    ```bash
    GET /api/v1/cvm/securit/ots_mensal?year=2024&month=1
    ```
  </Accordion>
</AccordionGroup>

### Example Usage

```python
# Get all CRA operations for January 2024
response = requests.get(
    "https://api.financialdata.com.br/api/v1/cvm/securit/cra_mensal",
    headers={"X-API-Key": "your_api_key"},
    params={"year": 2024, "month": 1}
)

cra_operations = response.json()['data']
print(f"CRA operations in Jan 2024: {len(cra_operations)}")
```

## Regulatory Framework

<AccordionGroup>
  <Accordion title="FIDC Regulation" icon="gavel">
    - CVM Instruction 356/2001
    - CVM Instruction 444/2006 (amendments)
    - Minimum 50% in credit rights
    - Quarterly reporting requirements
  </Accordion>
  
  <Accordion title="FIP Regulation" icon="gavel">
    - CVM Instruction 578/2016
    - Minimum 90% in equity
    - Active management requirements
    - Four-month reporting cycle
  </Accordion>
  
  <Accordion title="FIAGRO Regulation" icon="gavel">
    - Law 14.130/2021
    - CVM Instruction 175/2022
    - Minimum 67% in agribusiness assets
    - Tax exemption for individuals
  </Accordion>
  
  <Accordion title="Securitization Regulation" icon="gavel">
    - Law 9.514/1997 (CRI)
    - Law 11.076/2004 (CRA)
    - Law 10.931/2004 (LCI/LCA)
    - Monthly reporting requirements
  </Accordion>
</AccordionGroup>
