**src/cvm_api/db.py**:
```python
"""
CVM API async database session factory.

Creates an AsyncEngine reading CVM_DATABASE_URL from environment.
Exposes get_db() as a FastAPI dependency — injects AsyncSession per request.

Pool settings (QUERY-04):
  pool_size=5, max_overflow=10 → max 15 concurrent connections from this service.
  With 3 services: 3 × 15 = 45 peak connections, well within POSTGRES_MAX_CONNECTIONS=200.
"""
import os
from sqlalchemy.ext.asyncio import (
    create_async_engine,
    async_sessionmaker,
    AsyncSession,
)

# Raises KeyError on startup if env var is missing — fail fast, no silent misconfiguration
DATABASE_URL = os.environ["CVM_DATABASE_URL"]

engine = create_async_engine(
    DATABASE_URL,
    pool_size=5,
    max_overflow=10,
    pool_pre_ping=True,   # test connection health before checkout
    echo=False,
)

AsyncSessionLocal = async_sessionmaker(
    engine,
    class_=AsyncSession,
    expire_on_commit=False,  # REQUIRED for async — prevents MissingGreenlet after commit
)


async def get_db() -> AsyncSession:  # type: ignore[override]
    """FastAPI dependency: yields a per-request AsyncSession.

    Usage in route handlers (Phase 2+):
        async def my_route(db: AsyncSession = Depends(get_db)):
            result = await db.execute(select(SomeModel))
    """
    async with AsyncSessionLocal() as session:
        yield session
```

Read the current contents of each main.py before modifying. The key changes per file are:

**Pattern to apply to each main.py:**

1. Add import of `contextlib` at top (for `asynccontextmanager`)
2. Add import of `engine` from db.py inside the `if __package__` / `else` block:
   ```python
   if __package__:
       from .db import engine
   else:
       from db import engine
   ```
3. Add lifespan function before `app = FastAPI(...)`:
   ```python
   from contextlib import asynccontextmanager

   @asynccontextmanager
   async def lifespan(app: FastAPI):
       # startup: nothing to do — engine is created at module load
       yield
       # shutdown: dispose engine to close all pool connections cleanly
       await engine.dispose()
   ```
4. Pass `lifespan=lifespan` to `FastAPI(...)`:
   ```python
   app = FastAPI(
       ...existing args...,
       lifespan=lifespan,
   )
   ```

Do NOT add `get_db` to main.py imports in this phase. `get_db` will be imported in route handlers in Phase 2+ when routes actually use the DB. Importing it now would cause a startup failure if `*_DATABASE_URL` is not set (the engine creation at import time raises KeyError). The `engine` import is needed only for disposal.

Actually — reconsider: importing `engine` from db.py at module level in main.py will ALSO fail at import time if `*_DATABASE_URL` is not set. To avoid breaking the existing `python -m uvicorn` workflow for local development without a database, wrap the db import in a try/except that logs a warning but does not fail:

```python
# Lazy DB import: engine disposal only if DB is configured
_db_engine = None
try:
    if __package__:
        from .db import engine as _db_engine
    else:
        from db import engine as _db_engine
except KeyError:
    # DATABASE_URL not set — running without DB (local dev without postgres)
    import logging as _logging
    _logging.getLogger(__name__).warning(
        "DATABASE_URL not set — DB engine not initialized. "
        "Set *_DATABASE_URL env var to enable database connectivity."
    )

@asynccontextmanager
async def lifespan(app: FastAPI):
    yield
    if _db_engine is not None:
        await _db_engine.dispose()
```
