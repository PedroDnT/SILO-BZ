<decisions_made>

- PostgreSQL 16 (postgres:16-alpine) as the shared DB — single instance, three schemas (cvm, bacen, b3_calc)
- SQLAlchemy 2.x async + asyncpg at runtime; psycopg2-binary for Alembic migrations only
- DB-first-with-live-fallback pattern: query DB first, fall through to upstream on miss, write back async via BackgroundTasks
- One-shot db_migrate compose service runs Alembic before API services start (prevents migration race)
- ORM models in src/db/models/ as shared source of truth across services
- All existing API routes/response shapes preserved unchanged — QUERY-01 enforced by contract snapshot tests from Phase 1
- B3 CALC sample data fallback preserved as last resort; sample data must never be written to DB
