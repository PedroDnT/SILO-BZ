# Brazilian Financial Data API

A multi-service REST platform that exposes public Brazilian financial market data from three primary sources:

| Service | Port | Source | What it provides |
|---|---|---|---|
| **CVM Credit API** | 8000 | `dados.cvm.gov.br` | FIDC, FIP, FIAGRO, SECURIT fund data |
| **B3 CALC API** | 8001 | `calculadorarendafixa.com.br` | Fixed income pricing (debentures, CRA, CRI) |
| **BACEN API** | 8002 | Banco Central do Brasil | Interest rates, PTAX, Focus expectations |

## Key features

- **No authentication required** — CVM and BACEN endpoints are fully public.
- **Pagination built in** — every list endpoint supports `page` and `page_size` parameters.
- **Automatic caching** — CVM downloads are cached locally to reduce upstream load.
- **Resilient DNS** — configurable nameserver rotation for reliable CVM file downloads.
- **Docker-first** — all services ship with Dockerfiles and a single `docker-compose.yml`.
