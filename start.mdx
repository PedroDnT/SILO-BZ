# How to Use the CVM Credit Market API

This API provides transparent access to Brazilian CVM (Comissão de Valores Mobiliários) credit market datasets, including FIDC, FIP, FIAGRO, and SECURIT information, with support for flexible querying, historical records, and structured responses.

## API Endpoints

### Core Endpoints

- `GET /api/v1/cvm/{entity}/{doc_type}`  
  Returns data for a specific entity and document type.  
  Entities: `fidc`, `fip`, `fiagro`, `securit`  
  Document types: e.g. `cadastral`, `mensal`, `trimestral`, `anual` (see `/api/v1/endpoints` for all options)

- `GET /api/v1/cvm/fidc/cadastral`  
  Returns cadastral/registration data for FIDC (Fundo de Investimento em Direitos Creditórios) funds.

- `GET /api/v1/cvm/fip/cadastral`  
  Returns cadastral data for FIP (Private Equity Investment Funds).

### Query Parameters

All core endpoints support the following parameters:

| Parameter  | Type    | Required    | Description                                    |
| :--------- | :------ | :---------- | :---------------------------------------------- |
| `year`     | int     | Optional    | Year of interest (for periodic datasets)        |
| `month`    | int     | Optional    | Month of interest (for monthly datasets)        |
| `page`     | int     | Optional    | Page number (default: 1)                        |
| `page_size`| int     | Optional    | Number of results per page (default: 100)      |
