---
title: "SILO"
description: "Query Brazilian company filings, funds, prices, and macroeconomic data through REST or MCP."
---

Use SILO to retrieve Brazilian financial data for an application, an agent, or a research notebook. You can resolve an issuer or fund, check which periods are covered, and query the observations behind a result.

## What you can query

| Area | Start with |
| --- | --- |
| Companies | [Financial statements](/api-docs/v2/reference/statements) and [events](/api-docs/v2/reference/events) |
| Funds and credit | [Fund profiles and history](/api-docs/v2/reference/funds) and [FIDC disclosures](/api-docs/v2/reference/fidc) |
| Markets and macro | [Prices](/api-docs/v2/reference/prices), [curves](/api-docs/v2/reference/curves), and [macro series](/api-docs/v2/reference/macro) |
| Research | [Cross-asset panel](/api-docs/v2/reference/panel) and [point-in-time research guide](/api-docs/v2/researchers) |

SILO v2 is a deployed preview. Anonymous requests need no key. If you already use the original API or MCP server, follow the [v1 quickstart](/api-docs/quickstart).
