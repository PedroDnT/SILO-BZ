| 2026-11-03 | claude/1055-api-v2-prices-statements | **API v2: the `prices` and `statements` resources in `silo-api` (#1055, epic #1052).** `prices` maps `kind` `history` to `quote_history` (`adjust=split` selects `close_adj`, `adjust=none` the raw `close`), `latest` to `quote_latest`, `index` to `index_history`, `forward` to `trade_consolidated_history`, and `session` to one GET on a price view chosen by the hidden `asset_class` (`quotes`, `equities`, `bdrs`, `units`, `fund_quotas`, `cash_securities`, `auctions`), with a hidden `date` that defaults to the newest session. It reads through #1066's single `callView` (`Prefer: count=exact`), which gains a non-eq filter argument; a session over one page is refused (`over_limit`), never served cut. `freq=month` keeps the last session of each month from the daily rows, never a fill. Every price row carries `adjusted`; `fields=all` returns every column. `statements` maps `all`, `income`, `balance`, `cashflow`, `headline` and `versions` to `financials`, `income_statements`, `balance_sheets`, `cash_flow_statements`, `company_financials` and `financial_statement_history`; `period` becomes `p_doc_type` (`itr`, `dfp`), or a selection on `doc_type` for `headline`; `versions` takes a hidden `statement` (default `DRE`). With no `id`, both list the research universe. Default windows use #1066's `window_months` (12 and 60, the SQL's 365 and 1,825 days). The registry gains `view_by`, `uses`, value maps and a `month_last` selection; `tests/test_api_v2_registry.py` pins the history field list, the session view columns and the windows to the SQL. Deno tests were run under Bun with shims, not under Deno. No SQL changed; nothing deployed. |
