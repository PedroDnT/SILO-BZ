| 2026-10-06 | feat/worker-exposure-page | **An owner-only trace page on the Worker: where an asset's exposure comes from, and the stored PDF, from a phone.** `GET /traces` is a static page that asks for the access code (kept in memory only), lists the stored runs, shows for any asset held through several lines its direct part and one row per fund with the weight in the fund and the CDA month, and downloads the run's stored PDF. `GET /api/traces`, `/api/traces/exposure` and `/api/traces/pdf` need the same token as `/diagnose`, read the private bucket only through two strict key shapes, and send `no-store`; nothing is logged. The repository is public, so no workflow prints a run's content: the owner reads it through the Worker. `src/exposure.ts` holds the logic and `tests/test_worker_exposure.py` checks it against `scripts/trace_view.py exposure`. Checked locally with `wrangler dev` and a mobile-size browser on synthetic data. ADR 0003 and the Worker README updated. |
