Also: SDK 0.2.0 (truncation detection via `Content-Range`, `SiloTimeout`, bearer-token tier), `serve/` returns JSON on every error path, and **`docs/DATA_INVENTORY.md`** — what we ingest, what we could ingest and don't, what we ingest and don't serve, and the serving grain per family.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
