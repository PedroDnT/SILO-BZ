# Decisions

These are decisions the repository already records. Each row links to its
source. A new decision that is hard to reverse gets its own file in
[`docs/adr/`](../adr/).

| Decision                                                                                  | Why                                                                                                                      | Source                                                  |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------- |
| A failed fetch raises; nothing is fabricated                                              | Fake data corrupts every downstream metric (`b3_calc_api` was deleted)                                                   | [AGENTS.md](../../AGENTS.md), integrity rules           |
| Upsert on a named natural key; migrations are append-only                                 | Every run can be repeated safely                                                                                         | [AGENTS.md](../../AGENTS.md)                            |
| No ingest HTTP API, no Docker or Alembic, no fake quote API                               | Ingest is scheduled jobs; Supabase is the only state                                                                     | [README](../../README.md#whats-intentionally-not-here)  |
| Schema `api` is the only client surface; PostgREST never exposes `public`                 | One contract; landing tables can change                                                                                  | [API](../reference/API.md#layers)                       |
| Above 1,000 rows, refuse (22023); never truncate                                          | A silent cut reads as complete data                                                                                      | `api.assert_row_cap`, [AGENTS.md](../../AGENTS.md)      |
| Gate health on `landed_at`, not `complete_through`                                        | The source's calendar is not our outage                                                                                  | [AGENTS.md](../../AGENTS.md)                            |
| FII filings keep every version                                                            | Restatements sit beside originals; read `*_latest` views                                                                 | migration 43                                            |
| No backfill for the B3 BDI group                                                          | B3 keeps about 21 business days; a start year would promise the impossible                                               | `B3Ingestor.backfill` docstring                         |
| Every scheduled run whose analytical apply succeeds rebuilds the dashboard                | The snapshot is never more than a day behind (2026-09-14); a red source does not block it, and `landed_at` shows its age | `daily_ingest.yml` (#473)                               |
| FNET, market and B3 event steps run after publishing                                      | Slow foreign hosts must not block the analytical apply or the deploy                                                     | `daily_ingest.yml` (2026-09-25, 2026-09-30)             |
| Portfolio analysis stores no user portfolios                                              | Stateless by design                                                                                                      | [ADR 0001](../adr/0001-stateless-portfolio-analysis.md) |
| Diagnosis traces (masked engine JSON, HTML, PDF) go to private R2; the upload never             | Real runs improve the agents; Supabase stays without portfolios                                                          | [ADR 0003](../adr/0003-diagnosis-traces-in-r2.md)       |
| Debenture history and traded rates from REUNE (stored, never served raw), volume from B3; no cash-flow engine | Observed trades beat model marks; B3 keeps 18 months and has no rate | [ADR 0004](../adr/0004-debenture-market-data-sources.md) |
| Investigator facts are quotes from public documents, tiered A/B/C; no number from a model | Every fact is checkable; Exa only after Fundos.NET and RAD; read once, cached in the same R2                             | [#605](https://github.com/PedroDnT/SILO-BZ/issues/605)  |
| Times are shown in UTC-3                                                                  | The owner reads Brasília time; stored values are unchanged                                                               | [AGENTS.md](../../AGENTS.md)                            |
