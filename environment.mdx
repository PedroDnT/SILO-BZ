---
title: "Environment Variables"
description: "All environment variables supported by the platform and their defaults."
---

Copy `.env.example` to `.env` in the repository root to configure the services:

```bash
cp .env.example .env
```

All variables have sensible defaults, so you do not need to set any of them to get started.

---

## CVM Credit API

| Variable | Default | Description |
|---|---|---|
| `CVM_DNS_NAMESERVERS` | `1.1.1.1,8.8.8.8,9.9.9.9` | Comma-separated DNS resolvers used for CVM downloads. Rotated on retry. |
| `CVM_REQUEST_TIMEOUT` | `300` | HTTP request timeout in seconds |
| `CVM_MAX_RETRIES` | `3` | Maximum download retry attempts |
| `CVM_RETRY_DELAY` | `2` | Base delay (seconds) between retries (multiplied by attempt number) |
| `CACHE_TTL` | `3600` | Cache TTL in seconds (used for metadata; disk cache uses 24-hour fixed window) |

---

## B3 CALC API

| Variable | Default | Description |
|---|---|---|
| `B3_CALC_BASE_URL` | `https://calculadorarendafixa.com.br/webservice` | Upstream URL for the B3 CALC pricing service |

---

## BACEN API

| Variable | Default | Description |
|---|---|---|
| `BACEN_API_HOST` | `0.0.0.0` | Bind address |
| `BACEN_API_PORT` | `8002` | Port |

---

## Shared

| Variable | Default | Description |
|---|---|---|
| `LOG_LEVEL` | `INFO` | Logging level (`DEBUG`, `INFO`, `WARNING`, `ERROR`) |
| `TZ` | `America/Sao_Paulo` | Container timezone |
| `RATE_LIMIT_ENABLED` | `true` | Enable rate limiting (not yet wired to a handler) |
| `RATE_LIMIT_REQUESTS` | `100` | Maximum requests per window |
| `RATE_LIMIT_WINDOW` | `60` | Rate-limit window in seconds |

---

## Example `.env` file

```ini
# CVM API
CVM_DNS_NAMESERVERS=1.1.1.1,8.8.8.8,9.9.9.9
CACHE_TTL=3600

# B3 CALC API
B3_CALC_BASE_URL=https://calculadorarendafixa.com.br/webservice

# BACEN API
BACEN_API_HOST=0.0.0.0
BACEN_API_PORT=8002

# Shared
LOG_LEVEL=INFO
TZ=America/Sao_Paulo
```
