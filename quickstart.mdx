## Prerequisites

- Docker and Docker Compose installed, **or** Python 3.11+ with `pip`
- Git

## Option A — Docker Compose (recommended)

Clone the repository and start all services with a single command:

```bash
git clone https://github.com/PedroDnT/iliquid_nightly.git
cd iliquid_nightly
cp .env.example .env   # optional — defaults work out of the box
docker-compose up -d
```

The services will be available at:

| Service | URL |
|---|---|
| CVM Credit API | http://localhost:8000 |
| B3 CALC API | http://localhost:8001 |
| BACEN API | http://localhost:8002 |
| Docs (static) | http://localhost:8080 |

## Option B — Local Python

Install dependencies and run services individually:

```bash
pip install -r requirements.txt

# In separate terminals:
python -m uvicorn src.cvm_api.main:app --reload --host 0.0.0.0 --port 8000
python -m uvicorn src.b3_calc_api.main:app --reload --host 0.0.0.0 --port 8001
python -m uvicorn src.bacen_api.main:app --reload --host 0.0.0.0 --port 8002
```

<Warning>
Always use `python -m uvicorn` (not bare `uvicorn`) when running from the repo root. Bare `uvicorn` does not resolve `src.*` package imports correctly.
</Warning>

## Verify the setup

```bash
# CVM API health check
curl http://localhost:8000/health

# BACEN API — latest Selic rate
curl "http://localhost:8002/api/v1/bacen/sgs/11/latest"

# B3 CALC API — list available debentures
curl "http://localhost:8001/api/v1/securities/debentures?page_size=5"
```

## First requests

### Fetch FIDC monthly data

```bash
curl "http://localhost:8000/api/v1/fidc/mensal?year=2025&month=1&page=1&page_size=10"
```

### Get the USD/BRL exchange rate

```bash
curl "http://localhost:8002/api/v1/bacen/ptax/usd/latest"
```

### Price a debenture

```bash
curl "http://localhost:8001/api/v1/prices/XPCA11"
```
