## Overview

PTAX is the official exchange rate published by the Brazilian Central Bank (BACEN). It represents the average rate from currency transactions in the Brazilian market and is widely used for contracts, accounting, and financial reporting.

## USD/BRL Rate

Get the USD to BRL exchange rate for a specific date:

```bash
curl "https://api.financialdata.com.br/api/v1/bacen/ptax/dolar?date=2024-01-15"
```

### Parameters

- `date` (query, required): Date in ISO format (YYYY-MM-DD)

### Response

```json
{
  "query_type": "CotacaoDolarDia",
  "total_records": 1,
  "data": [
    {
      "date": "2024-01-15",
      "cotacao_compra": 4.9234,
      "cotacao_venda": 4.9240
    }
  ],
  "timestamp": "2024-01-15T10:30:00Z"
}
```

## USD/BRL Period

Get USD/BRL rates for a date range:

```bash
curl "https://api.financialdata.com.br/api/v1/bacen/ptax/dolar/periodo?start=2024-01-01&end=2024-01-31"
```

### Parameters

- `start` (query, required): Start date in ISO format
- `end` (query, required): End date in ISO format

### Response

## Other Currencies

Get exchange rate for any available currency:

```bash
curl "https://api.financialdata.com.br/api/v1/bacen/ptax/moeda/EUR?date=2024-01-15"
```

### Parameters

- `moeda` (path, required): Currency code (EUR, GBP, JPY, etc.)
- `date` (query, required): Date in ISO format

### Response

```json
{
  "query_type": "CotacaoMoedaDia",
  "moeda": "EUR",
  "total_records": 1,
  "data": [
    {
      "date": "2024-01-15",
      "cotacao_compra": 5.3421,
      "cotacao_venda": 5.3428
    }
  ],
  "timestamp": "2024-01-15T10:30:00Z"
}
```

## Currency Period

Get rates for any currency over a date range:

```bash
curl "https://api.financialdata.com.br/api/v1/bacen/ptax/moeda/EUR/periodo?start=2024-01-01&end=2024-01-31"
```

## Understanding PTAX

### Buy vs Sell Rates

- `cotacao_compra`: Buy rate (what banks pay for foreign currency)
- `cotacao_venda`: Sell rate (what banks charge for foreign currency)

The sell rate is typically slightly higher than the buy rate, representing the bank's spread.

### Business Days Only

PTAX rates are only published on business days. Weekend and holiday requests will return the last available rate.

### Publication Time

PTAX rates are typically published around 1:00 PM (Brasília time) each business day.
