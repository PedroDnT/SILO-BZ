## Introduction

The BACEN (Banco Central do Brasil) API provides access to over 18,000 economic time series from Brazil's Central Bank, including interest rates, exchange rates, inflation indices, and market expectations.

## Popular Series

### Interest Rates

| Series | Code | Description |
|--------|------|-------------|
| SELIC Meta | 432 | SELIC target rate set by COPOM |
| SELIC Diária | 11 | Daily SELIC rate |
| CDI | 12 | Interbank deposit certificate rate |
| Taxa Referencial (TR) | 226 | Reference rate |

### Inflation Indices

| Series | Code | Description |
|--------|------|-------------|
| IPCA | 433 | Consumer price index |
| IGP-M | 189 | General price index - market |
| IGP-DI | 190 | General price index - internal availability |
| INPC | 188 | National consumer price index |

### Exchange Rates

| Series | Code | Description |
|--------|------|-------------|
| USD/BRL | 1 | US Dollar to Brazilian Real |
| EUR/BRL | 21619 | Euro to Brazilian Real |
| GBP/BRL | 21621 | British Pound to Brazilian Real |

## Quick Start

### Get SELIC Rate

```bash
GET /api/v1/bacen/sgs/432
```

<CodeGroup>

```python Python
import requests

response = requests.get(
    "https://api.financialdata.com.br/api/v1/bacen/sgs/432",
    headers={"X-API-Key": "your_api_key"},
    params={
        "start_date": "2023-01-01",
        "end_date": "2023-12-31"
    }
)

selic_data = response.json()['data']
for record in selic_data[:5]:
    print(f"{record['date']}: {record['value']}%")
```

```javascript JavaScript
const response = await fetch(
    'https://api.financialdata.com.br/api/v1/bacen/sgs/432?start_date=2023-01-01&end_date=2023-12-31',
    { headers: { 'X-API-Key': 'your_api_key' } }
);

const { data: selicData } = await response.json();
selicData.slice(0, 5).forEach(record => {
    console.log(`${record.date}: ${record.value}%`);
});
```

</CodeGroup>

### Get USD/BRL Exchange Rate

```bash
GET /api/v1/bacen/ptax/dolar?date=2024-02-26
```

<CodeGroup>

```python Python
response = requests.get(
    "https://api.financialdata.com.br/api/v1/bacen/ptax/dolar",
    headers={"X-API-Key": "your_api_key"},
    params={"date": "2024-02-26"}
)

ptax = response.json()['data']
print(f"USD/BRL: {ptax['buy']} / {ptax['sell']}")
```

```javascript JavaScript
const response = await fetch(
```

</CodeGroup>

### Get Market Expectations

```bash
GET /api/v1/bacen/expectativas/ExpectativasMercadoAnuais?indicador=IPCA
```

<CodeGroup>

```python Python
response = requests.get(
    "https://api.financialdata.com.br/api/v1/bacen/expectativas/ExpectativasMercadoAnuais",
    headers={"X-API-Key": "your_api_key"},
    params={"indicador": "IPCA", "limit": 10}
)

expectations = response.json()['data']
for exp in expectations:
    print(f"{exp['Data']}: {exp['Mediana']}%")
```

```javascript JavaScript
const response = await fetch(
    'https://api.financialdata.com.br/api/v1/bacen/expectativas/ExpectativasMercadoAnuais?indicador=IPCA&limit=10',
    { headers: { 'X-API-Key': 'your_api_key' } }
);

const { data: expectations } = await response.json();
expectations.forEach(exp => {
    console.log(`${exp.Data}: ${exp.Mediana}%`);
});
```

</CodeGroup>

## Common Use Cases

### Economic Analysis

Track key economic indicators over time:

```python
def get_economic_dashboard():
    """Get current values for key indicators"""
    indicators = {
        'SELIC': 432,
        'CDI': 12,
        'IPCA': 433,
        'USD/BRL': 1
    }
    
    dashboard = {}
    for name, code in indicators.items():
        response = requests.get(
            f"https://api.financialdata.com.br/api/v1/bacen/sgs/{code}",
            headers={"X-API-Key": "your_api_key"},
            params={"last": 1}
        )
        data = response.json()['data']
        if data:
            dashboard[name] = data[0]['value']
    
    return dashboard

dashboard = get_economic_dashboard()
print("Economic Dashboard:")
for indicator, value in dashboard.items():
    print(f"  {indicator}: {value}")
```

### Currency Conversion

Get historical exchange rates for currency conversion:

```python
def convert_currency(amount, from_currency, to_currency, date):
    """Convert currency using PTAX rates"""
    if from_currency == "USD" and to_currency == "BRL":
        response = requests.get(
            "https://api.financialdata.com.br/api/v1/bacen/ptax/dolar",
            headers={"X-API-Key": "your_api_key"},
            params={"date": date}
        )
        rate = response.json()['data']['sell']
        return amount * rate
    
    # Add more currency pairs as needed
    raise ValueError(f"Conversion {from_currency} to {to_currency} not supported")

# Convert $1000 USD to BRL on 2024-02-26
brl_amount = convert_currency(1000, "USD", "BRL", "2024-02-26")
print(f"$1000 USD = R$ {brl_amount:.2f}")
```
