## Overview

The Focus bulletin (Boletim Focus) is a weekly report published by the Brazilian Central Bank containing market expectations for key economic indicators. This data is collected from financial institutions, consultancies, and other market participants.

## Available Endpoints

Get a list of all available expectations endpoints:

```bash
curl https://api.financialdata.com.br/api/v1/bacen/expectativas
```

### Response

```json
{
  "endpoints": [
    "ExpectativasMercadoAnuais",
    "ExpectativasMercadoMensais",
    "ExpectativasMercadoTrimestrais",
    "ExpectativasMercadoSelic",
    "ExpectativasMercadoTop5Anuais",
    "ExpectativasMercadoTop5Mensais"
  ],
  "timestamp": "2024-01-15T10:30:00Z"
}
```

## Query Expectations

Query a specific expectations endpoint:

```bash
curl "https://api.financialdata.com.br/api/v1/bacen/expectativas/ExpectativasMercadoMensais?indicador=IPCA&start=2024-01-01&limit=100"
```

### Parameters

- `endpoint_name` (path, required): Expectations endpoint name
- `indicador` (query, optional): Filter by indicator (IPCA, Selic, PIB Total, Câmbio, etc.)
- `start` (query, optional): Filter by date >= this ISO date
- `limit` (query, optional): Maximum rows to return (1-1000, default: 100)

### Response

```json
{
  "endpoint": "ExpectativasMercadoMensais",
  "indicador": "IPCA",
  "start_date": "2024-01-01",
  "total_records": 45,

```

## Common Indicators

### Inflation Indicators

- `IPCA`: Consumer price index
- `IGP-M`: General price index
- `IGP-DI`: General price index - internal availability

### Interest Rates

- `Selic`: SELIC target rate
- `Taxa de câmbio`: Exchange rate (USD/BRL)

### Economic Activity

- `PIB Total`: Total GDP
- `PIB Agropecuária`: Agricultural GDP
- `PIB Indústria`: Industrial GDP
- `PIB Serviços`: Services GDP

### Fiscal Indicators

- `Resultado Primário`: Primary fiscal result
- `Resultado Nominal`: Nominal fiscal result
- `Dívida líquida do setor público`: Public sector net debt

## Understanding the Data

### Statistical Measures

- `Media`: Mean of all forecasts
- `Mediana`: Median of all forecasts
- `DesvioPadrao`: Standard deviation
- `Minimo`: Minimum forecast
- `Maximo`: Maximum forecast
- `numeroRespondentes`: Number of respondents

### Data Reference

- `Data`: Survey date
- `DataReferencia`: Reference period for the forecast

### Interpretation

- Higher standard deviation indicates greater uncertainty
- Median is often more reliable than mean for skewed distributions
- Number of respondents indicates survey participation

## Use Cases

- Economic forecasting and modeling
- Investment decision making
- Risk assessment
- Policy analysis
- Market sentiment tracking
- Research and academic studies

## Update Frequency

- Focus bulletin is published weekly (typically Mondays)
- Data reflects expectations as of the survey date
- Historical data available for trend analysis

## Rate Limits

- 100 requests per minute per IP
- Use the `limit` parameter to control response size
- Consider caching weekly data
