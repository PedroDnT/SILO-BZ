## Overview

All list endpoints return paginated results to ensure optimal performance. The API uses offset-based pagination with configurable page sizes.

## Pagination Parameters

<ParamField query="page" type="integer" default="1">
  Page number to retrieve (starts at 1)
</ParamField>

<ParamField query="page_size" type="integer" default="100">
  Number of items per page
  - Minimum: 1
  - Maximum: 10,000
  - Default: 100
</ParamField>

## Response Structure

Every paginated response includes a `pagination` object:

```json
{
  "data": [...],
  "pagination": {
    "page": 1,
    "page_size": 100,
    "total_items": 1500,
    "total_pages": 15
  }
}
```

<ResponseField name="page" type="integer">
  Current page number
</ResponseField>

<ResponseField name="page_size" type="integer">
  Number of items in the current page
</ResponseField>

<ResponseField name="total_items" type="integer">
  Total number of items across all pages
</ResponseField>

<ResponseField name="total_pages" type="integer">
  Total number of pages available
</ResponseField>

## Iterating Through Pages

### Python Example

```python
import requests

def fetch_all_pages(url, headers):
    """Fetch all pages of data"""
    all_data = []
    page = 1
    
    while True:
        response = requests.get(
            url,
            headers=headers,
            params={"page": page, "page_size": 100}
        )
        
        result = response.json()
        all_data.extend(result['data'])
        
        # Check if we've reached the last page
        if page >= result['pagination']['total_pages']:
            break
            
        page += 1
    
    return all_data

# Usage
all_records = fetch_all_pages(
    "https://api.financialdata.com.br/api/v1/cvm/fidc/cadastral",
    headers={"X-API-Key": "your_api_key"}
)

print(f"Retrieved {len(all_records)} total records")
```

### JavaScript Example

```javascript
async function fetchAllPages(url, headers) {
    const allData = [];
    let page = 1;
    
    while (true) {
        const response = await fetch(
            `${url}?page=${page}&page_size=100`,
            { headers }
        );
        
        const result = await response.json();
        allData.push(...result.data);
        
        // Check if we've reached the last page
        if (page >= result.pagination.total_pages) {
            break;
        }
        
        page++;
    }
    
    return allData;
}

// Usage
const allRecords = await fetchAllPages(
    'https://api.financialdata.com.br/api/v1/cvm/fidc/cadastral',
    { 'X-API-Key': 'your_api_key' }
);

console.log(`Retrieved ${allRecords.length} total records`);
```

## Best Practices

<AccordionGroup>
  <Accordion title="Choose appropriate page sizes" icon="sliders">
    - Use smaller page sizes (10-50) for UI pagination
    - Use larger page sizes (500-1000) for batch processing
    - Balance between number of requests and response size
  </Accordion>
  
  <Accordion title="Handle rate limits" icon="gauge">
    When fetching multiple pages, implement delays to avoid rate limits:
    ```python
    import time
    
    for page in range(1, total_pages + 1):
        response = fetch_page(page)
        process_data(response)
        time.sleep(0.1)  # 100ms delay between requests
    ```
  </Accordion>
  
  <Accordion title="Cache results" icon="database">
    Cache paginated results to reduce API calls:
    - Store results in local database
    - Use Redis for temporary caching
    - Implement ETags for conditional requests
  </Accordion>
  
  <Accordion title="Monitor progress" icon="chart-line">
    Show progress when fetching multiple pages:
    ```python
    from tqdm import tqdm
    
    for page in tqdm(range(1, total_pages + 1)):
        fetch_and_process_page(page)
    ```
  </Accordion>
</AccordionGroup>

## Pagination Limits

<Warning>
  The maximum page size is 10,000 items. Requesting more will return a 400 error.
</Warning>

```json Error Response
{
  "error": "ValidationError",
  "message": "page_size exceeds maximum allowed value",
  "details": {
    "max_page_size": 10000,
    "requested": 15000
  },
  "timestamp": "2024-02-26T10:00:00Z"
}
```

## Performance Tips

<Tip>
  For large datasets, consider using filters to reduce the total number of items before paginating.
</Tip>

### Example: Filter Before Paginating

```python
# Instead of fetching all 10,000 records
response = requests.get(
    "https://api.financialdata.com.br/api/v1/cvm/fidc/cadastral",
    headers=headers,
    params={"page_size": 10000}
)

# Filter by date to reduce dataset size
response = requests.get(
    "https://api.financialdata.com.br/api/v1/cvm/fidc/mensal",
    headers=headers,
    params={
        "year": 2024,
        "month": 1,
        "page_size": 1000
    }
)
```
