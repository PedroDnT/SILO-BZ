---
title: 'List CVM Operations'
api: 'GET /api/v1/cvm/{entity}/{doc_type}'
description: 'Retrieve paginated list of CVM credit market data'
---

## Path Parameters

<ParamField path="entity" type="string" required>
  Entity type: `fidc`, `fip`, `fiagro`, or `securit`
</ParamField>

<ParamField path="doc_type" type="string" required>
  Document type (varies by entity):
  - FIDC: `cadastral`, `mensal`, `trimestral`, `anual`
  - FIP: `cadastral`, `inf_quadrimestral`, `inf_trimestral`, `dfin`
  - FIAGRO: `cadastral`, `mensal`, `trimestral`, `anual`
  - SECURIT: `cra_mensal`, `cri_mensal`, `ots_mensal`, `lca_mensal`, `lci_mensal`
</ParamField>

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number (minimum: 1)
</ParamField>

<ParamField query="page_size" type="integer" default="100">
  Items per page (minimum: 1, maximum: 10,000)
</ParamField>

<ParamField query="year" type="integer">
  Filter by year (required for some document types)
</ParamField>

<ParamField query="month" type="integer">
  Filter by month 1-12 (required for monthly document types)
</ParamField>

## Response

<ResponseField name="data" type="array">
  Array of records (structure varies by entity and document type)
</ResponseField>

<ResponseField name="pagination" type="object">
  Pagination information
  <Expandable title="properties">
    <ResponseField name="page" type="integer">
      Current page number
    </ResponseField>
    <ResponseField name="page_size" type="integer">
      Items per page
    </ResponseField>
    <ResponseField name="total_items" type="integer">
      Total number of items
    </ResponseField>
    <ResponseField name="total_pages" type="integer">
      Total number of pages
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="metadata" type="object">
  Request metadata
  <Expandable title="properties">
    <ResponseField name="entity" type="string">
      Entity type
    </ResponseField>
    <ResponseField name="doc_type" type="string">
      Document type
    </ResponseField>
    <ResponseField name="timestamp" type="string">
      Response timestamp (ISO 8601)
    </ResponseField>
  </Expandable>
</ResponseField>

## Examples

### Get FIDC Cadastral Data

```bash
GET /api/v1/cvm/fidc/cadastral?page=1&page_size=100
```

### Get FIP Monthly Data for December 2023

```bash
GET /api/v1/cvm/fip/inf_trimestral?year=2023&month=12&page=1&page_size=50
```

### Get SECURIT CRA Monthly Data

```bash
GET /api/v1/cvm/securit/cra_mensal?year=2024&month=1
```
