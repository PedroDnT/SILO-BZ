## Overview

Use this endpoint to monitor the API health and check the status of all dependent services. This endpoint is useful for:

- Load balancer health checks
- Monitoring and alerting systems
- Service status dashboards
- Uptime monitoring

## Response

<ResponseField name="status" type="string">
  Overall service status: `healthy`, `degraded`, or `unhealthy`
</ResponseField>

<ResponseField name="timestamp" type="string">
  Current server timestamp (ISO 8601 format)
</ResponseField>

<ResponseField name="version" type="string">
  API version
</ResponseField>

<ResponseField name="services" type="object">
  Status of individual services
  <Expandable title="properties">
    <ResponseField name="cvm_api" type="string">
      CVM service status
    </ResponseField>
    <ResponseField name="bacen_api" type="string">
      BACEN service status
    </ResponseField>
    <ResponseField name="b3_calc_api" type="string">
      B3 CALC service status
    </ResponseField>
    <ResponseField name="database" type="string">
      Database status
    </ResponseField>
    <ResponseField name="cache" type="string">
      Cache service status
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.financialdata.com.br/health"
```

```python Python
import requests

response = requests.get("https://api.financialdata.com.br/health")
health = response.json()

if health['status'] == 'healthy':
    print("✓ All systems operational")
else:
    print(f"⚠ System status: {health['status']}")
    for service, status in health['services'].items():
        print(f"  {service}: {status}")
```

```javascript JavaScript
const response = await fetch('https://api.financialdata.com.br/health');
const health = await response.json();

if (health.status === 'healthy') {
    console.log('✓ All systems operational');
} else {
    console.log(`⚠ System status: ${health.status}`);
    Object.entries(health.services).forEach(([service, status]) => {
        console.log(`  ${service}: ${status}`);
    });
}
```

## Status Values

<AccordionGroup>
  <Accordion title="healthy" icon="circle-check">
    All systems are operational and performing normally
  </Accordion>
  
  <Accordion title="degraded" icon="circle-exclamation">
    One or more services are experiencing issues but the API is still functional
  </Accordion>
  
  <Accordion title="unhealthy" icon="circle-xmark">
    Critical services are down and the API may not function correctly
  </Accordion>
</AccordionGroup>

## Monitoring Best Practices

<Tip>
  Set up automated health checks every 30-60 seconds to monitor API availability.
</Tip>

### Example Monitoring Script

```python Python
import requests
import time
from datetime import datetime

def monitor_health(interval=60):
    """Monitor API health at regular intervals"""
    while True:
        try:
            response = requests.get(
                "https://api.financialdata.com.br/health",
                timeout=10
            )
            health = response.json()
            
            timestamp = datetime.now().isoformat()
            status = health['status']
            
            if status == 'healthy':
                print(f"[{timestamp}] ✓ Status: {status}")
            else:
                print(f"[{timestamp}] ⚠ Status: {status}")
                # Send alert notification
                send_alert(health)
                
        except Exception as e:
            print(f"[{timestamp}] ✗ Health check failed: {e}")
            # Send critical alert
            send_critical_alert(str(e))
        
        time.sleep(interval)

monitor_health()
```
