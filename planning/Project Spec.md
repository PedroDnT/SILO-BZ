# CVM Credit Market API - File Bundle

This directory contains all source files for the Brazilian financial data infrastructure.

## Quick Start

1. **CVM Credit API** (FastAPI service)
   - See `cvm-credit-api/` directory
   - Run: `docker-compose up`

2. **ANBIMA/BACEN Clients** 
   - See `clients/` directory
   - Install: `pip install -r requirements.txt`

3. **Historical Backfill**
   - See `backfill/` directory
   - Run: `python backfill.py --help`
